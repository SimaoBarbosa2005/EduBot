Arquitetura

O EduBot liga uma interface web em HTML, uma API FastAPI, um motor de chat com recuperacao de contexto e um indice vetorial construido a partir dos documentos.

1

Interface Web

O utilizador navega entre introducao, chatbot e arquitetura no mesmo ficheiro.

2

FastAPI

Recebe mensagens, pedidos de reindexacao, consulta de documentos e crawling.

3

RAG Engine

Procura chunks relevantes, monta contexto e envia a pergunta ao motor de resposta.

4

Fontes

Documentos locais e paginas recolhidas alimentam o indice vetorial persistente.

Frontend

Uma SPA simples com navegacao por hash, mantendo tudo acessivel por um unico servidor.

Backend

  • /chat responde em streaming.
  • /retrieve devolve resultados RAG.
  • /documents resume documentos e chunks.

Dados

O indice e reconstruido quando necessario e reutilizado quando ja existem chunks guardados.
